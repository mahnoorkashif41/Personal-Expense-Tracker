# Aether Ledger — Personal Expense Tracker

A polished single-page expense dashboard built with Vite, TypeScript, CSS, and Chart.js. Data stays in the browser via `localStorage`.

## Run locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints (default `http://localhost:5173`).

## Features

- Add, edit, and delete expenses
- Title, amount, category, and date
- Search, category filter, and sorting
- Live monthly stats and budget progress
- Line, doughnut, and bar charts
- CSV export of the current list
- Responsive layout for phone, tablet, and desktop

## Production build

```bash
npm run build
npm run preview
```
